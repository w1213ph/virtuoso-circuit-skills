# 把你的任务交给 AI

先选下面一个场景，复制对应提示，再把方括号里的内容换成你的要求。论文直接作为附件提供；工程位置应当是 AI 实际可访问的位置。

AI 需要能读取仓库文件。若它打不开 GitHub，就下载仓库，放进 AI 可读取的项目目录，并把提示中的网址换成本地仓库位置。环境准备见 [SETUP.md](SETUP.md)。

## 先说明你的任务

不必重复填写项目中已经有的信息，写“从当前项目配置读取”即可。

| 信息 | 怎么填 |
|---|---|
| 任务范围 | 新论文 / 整理图 / 搬环境 / 导出；可组合，说明哪些需要仿真 |
| 论文范围或现有电路 | 论文附件＋图号/章节，或库名/cell/view |
| 工艺与电源 | 真实 PDK 库名、版本、电压；整理图时写“保持现有值” |
| 指标与优先级 | 例如先保证线性度，再满足噪声和匹配；说明带宽定义 |
| 工程位置 | 当前工程目录和新输出位置 |
| 可用连接 | 已有桥接工具、本机终端或 SSH；配置保存在本地 |

例如，RF 电路可以写：“LO=1 GHz，基带单边带宽 10 MHz，带内线性度优先，NF 尽量低于 9 dB，S11 尽量匹配，周期分析优先 HB。”这只是需求写法示例，具体指标应由你决定。

## 搭建新论文电路

```text
请使用 https://github.com/w1213ph/virtuoso-circuit-skills。
先读 AGENTS.md 和 skills/paper-to-virtuoso/SKILL.md，再按任务读取 references。

论文：[附件名称]；范围：[图号或章节]。
工艺：[实际 PDK 库名与版本]；电源：[电压]。
目标：[带宽/采样率、增益、噪声、线性度等，以及优先级]。
工程与输出位置：[目录]；连接方式：[本地配置或已有工具]。

请先讲清电路机制，列出论文给出的内容和需要补充设计的部分。
读取实际 PDK 器件、端子、CDF 参数和回调，确定工艺映射。
在独立库搭建真实电路、功能 symbol、测试台和仿真环境，先模块再整机验证。
图形参照仓库 CTDSM18 示例：功能可辨、尺寸紧凑、父级同步收紧，
主要通路和反馈用实体线，cell 名称采用大写项目前缀＋功能＋必要特征。
保留已有手工修改和正在运行的 Virtuoso 会话。
交付工程打开入口、实际模型与测量条件、连接/网表检查、仿真结果、
全图/局部/父级的实际截图，以及限制、未达标项和回退方法。
```

论文没给出的尺寸、偏置、CMFB、参考或数字控制，AI 应明确标为补充设计。仿真达不到论文结果时，应保留实际结果并说明差异。

## 整理已有原理图和 symbol

```text
请使用 https://github.com/w1213ph/virtuoso-circuit-skills。
读取 AGENTS.md、skills/paper-to-virtuoso/SKILL.md，
以及该 Skill 的 references/drawing.md、symbols.md、migration.md、acceptance.md。

现有工程：[目录]；库与 cell：[名称或清单]；新输出位置：[目录]。
只整理 schematic/symbol、规范命名，并迁移现有 Maestro。
保持器件参数、拓扑、模型和仿真设置，不启动新仿真。

先保存现有已保存状态和手工修改，再在独立库整理。
每个 symbol 表达自己的功能，按内容确定紧凑尺寸；缩小后同步父级实例、
间距和完整引出路径。主路径、反馈与差分支路用实体线，器件对齐，标注清楚。
比较前后参数、逐端网络和原生网表；实际检查全图、关键局部和直接父级。
迁移 Maestro 后逐项回读，不把旧仿真结果写成本轮新结果。
交付新库/cell/view 入口、截图、检查报告和回退方法。
```

不需要迁移环境时，删去提示中相关要求即可。参考图形、端口位置和父级排布见 [CTDSM18 案例](../examples/ctdsm18/README.md)。

```text

不包含 PDK 模型或连接密钥。给出文件清单、打开方法和缺失依赖。
```

## 最后让 AI 怎么汇报？

一份容易接手的交付应当包含：

1. **从哪里打开**：工程目录、库、顶层 cell/view、Maestro 入口。
2. **做了什么**：搭建或修改的模块，论文之外的补充设计。
3. **检查了什么**：参数/连接、原生网表、仿真行为和 GUI 目视的独立结论与证据。
4. **结果如何**：指标、测量条件、未完成项；改图任务说明未重跑仿真。
5. **怎样恢复**：备份位置和可执行回退方法。

AI 可用[验收模板](../skills/paper-to-virtuoso/assets/acceptance-template.json)记录细项，同时给你可读的说明。[验收清单](../skills/paper-to-virtuoso/references/acceptance.md)解释每类检查的含义。
