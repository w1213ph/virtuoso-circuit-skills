# 给其他 AI 的交接提示

把仓库链接、论文和以下某一段一起提供。AI 需要能够访问本机文件、合适的工具和使用者授权的 Virtuoso 环境；普通网页聊天不能自行取得这些能力。

## 搭建新论文

```text
读取本仓库 AGENTS.md 和 skills/paper-to-virtuoso/SKILL.md。
按我附上的论文和图号，用我指定的工艺、电源、带宽/采样率搭建。
先读取实际 PDK cell、端子、CDF 与回调，不照搬其他工艺的 W/L。
对论文没有给出的偏置、CMFB、尺寸、参考和数字控制明确标注补充设计。
symbol 参照 CTDSM18 的功能图形和紧凑比例；父级同步收紧并使用实体主路径。
在独立库完成原生电路、测试台和环境，先模块再整机验证。
交付实际模型/变量/测量条件、连接与网表检查、真实画面、结果、限制及回退。
```

还需给出：目标 PDK、VDD、优先指标、目标目录和连接方式。如果这些已在本地工程配置中提供，AI 应先读取，不反复询问。

## 只整理已有电路，达到 CTDSM18 的画图效果

```text
读取本仓库 AGENTS.md、SKILL.md 及 drawing/symbols/migration/acceptance。
只整理我指定工程的 schematic 和 symbol，并迁移现有 Maestro。
先保存当前已保存状态与手工修改，保持器件参数、拓扑、模型和仿真设置不变。
cell 使用项目前缀＋功能命名，view 保持原约定。
每个 symbol 表达自己的功能；按内容缩小，不要统一的大空框。
缩小后移动直接父级实例并重接引出路径，避免大间距和旧折线残留。
主要拓扑、反馈、差分支路使用实体线，器件对齐镜像，文字不遮挡。
比较前后参数、逐端网络与原生网表，检查全图、关键局部和真实父级。
不启动新仿真；不能把旧结果写成此次重排新验证。
```

## 仅导出已保存工程或整理历史结果

```text
只读导出我指定工程当前已保存的状态。不要强制保存、关闭或重载我的窗口。
排除锁和编辑器备份，打包前后核对源哈希；明确未保存修改不在包内。
新版工程与历史仿真分目录，保留原始条件，不能把旧 history 当成新版运行。
不包含 PDK 模型或连接密钥。
```

## 如何判定完成

让 AI 填写 [acceptance 模板](../skills/paper-to-virtuoso/assets/acceptance-template.json)，给出实际证据。写“检查通过”时需说明是哪一类检查。打不开原生 GUI 时，画面验收应写未完成。
