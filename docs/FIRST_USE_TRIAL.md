# 第一次用一个 agent 为 ADC 设计电路

在空目录把仓库链接和下列任意一道题交给一个能读写工程、运行命令的 agent。用 Linux、Python 3、Xschem 和 ngspice 可以本地生成和前仿，也可以在自己的 GitHub fork 提交规格。请记录实际打开的是原生编辑器还是预览图。[项目仓库](https://github.com/w1213ph/virtuoso-circuit-skills)

## 偏置支路

> 我要给 ADC 复制外部 8 µA 参考电流，输出支路向地拉电流。参考节点接 **275 fF**，输出在 **0.40–1.20 V** 时电流误差最多 **8%**。输出固定在 **0.80 V**，参考电流达到 99% 后，希望 **40 ns** 内进入并保持在稳态值的 **±1%**。请分别试 SKY130 和 GF180 的三组示例工况。在每种工艺里，选两管栅面积最小的达标版本；如果都超限，请指出哪次测量说明了原因。给我可以打开的图和可以复算的结果。

**要先看一次交付**，直接下载这道题的 ZIP，解压并用浏览器打开 `index.html`。可以点开实际测试台、最差工况的误差曲线和原始数据。打开解压目录的终端运行 `python bias.py`，Windows 也只需 Python 3。要重新设计，修改工程内的 `my-bias.json`，再按页面中的命令生成新的测试台。试用记录请注明采用了哪种起点。[下载 275 fF 实测工程](https://github.com/w1213ph/virtuoso-circuit-skills/releases/download/adc-bias-first-use-v1/adc-bias-275ff.zip)

## 采样驱动器

> 给我的 8 位 ADC 设计一个 SKY130 采样驱动器。量化范围 1 V，输入在 0.85 V 和 1.05 V 间变化，采样电容 1.25 pF。用 85 ns 跟踪，再保持 25 ns，两个方向上采样电容的误差都要在半个 LSB 内。跟踪和保持状态的相位裕度都至少 60°。请比较两组尺寸，给我能打开的电路和波形。如果两组都超限，指出最差的那次测量，说明下一步该检查哪里。

可以从空目录直接生成，也可以先下载 7 位、1 pF 示例，让 agent 用上述新规格重新设计。请在测试台找到采样电容所在的节点，用自己的话说明放大器输出与采样电压的区别，并从原始波形复算至少一项判定。[下载 7 位示例](https://github.com/w1213ph/virtuoso-circuit-skills/releases/download/adc-driver-7bit-v1/adc-driver-7bit.zip) · [提交自定义采样规格](../examples/sky130-adc-driver/README.md)
