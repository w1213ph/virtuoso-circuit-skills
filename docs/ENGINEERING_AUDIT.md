## 本轮独立验收

SMIC18、IC6.1.8、Spectre 15.1。比较器的拓扑、设计尺寸和绘图代码沿用基线。两种几何分别为 2.700 和 2.844 µm² 栅面积。原生回读每版 11 个 MOS 共 44 个端子、7 个父级引线。两版 symbol 与测试台导出像素相同，核心图差异位于输入管的尺寸标注。GUI 的目视证据只覆盖这三种视图。Maestro 的证据来自原生保存、另一进程重开、真实历史和重新提取的波形。[可复跑案例、工况与截图](../examples/dynamic-comparator/README.md)

最终验收包含 16 次直接瞬态、16 次 Maestro 瞬态、64 次 mismatch 瞬态，以及两种 MOS 在 TT 和 SS 共四次 DC 扫描，每次生成 9 条器件曲线、1,629 行查表数据。另用原生 SI 的四种 MOS 做了 16 组匹配对 DC 校准。正负输入每种各 16 组抽样，保留实际向量摘要。独立进程复核原配置和原始波形，两种器件在 TT 返回 0，在 SS 均返回 1 并指明延迟超限。用普通器件配置查统计器件工程会返回证据错误。普通器件的抽样不能证实失配，统计器件则出现了可重复的错误判决。没有用户手动操作 EDA 的步骤，也未做盲测新手试用。执行环境未提供本轮模型 token 用量。[机器可读结果](../examples/dynamic-comparator/native-review.json)

## 如何评分

**本次比较器的前端工程质量为 73/100，成熟度保守记为 L2。** 每个维度设两道等权检查，通过一项计该维度一半分。已观测失败记零分，无证据也记零分。20 项中有 17 项有直接证据或明确的未通过结果。缺的是定量再生理论交叉验证、真实时钟前级集成、端间应力验证。统计器件已产生可观测的实际失配，其中有错误判决，慢角延迟也超过预算，故电路鲁棒性维度计零。

| 检查 | 分数 | 两项依据 |
|---|---:|---|
| 电气正确性 | 10/10 | 回读全部 MOS 端子；比较实际两条网表路径 |
| 理论与器件 | 5/10 | 有工艺查表；缺定量再生时间常数对照 |
| 辅助电路 | 5/10 | 明确外部时钟与供电接口；实际时钟前级未集成 |
| 原理图 | 10/10 | 差分支路与反馈可辨；原生全图及局部已看 |
| Symbol 与层次 | 8/8 | 端序一致；父级首段按所在侧向外 |
| 测试台与 Maestro | 10/10 | 有两种极性的工作台；重开后产生可复算历史 |
| 标称性能与优化 | 15/15 | 三项开发预算均满足；同条件量化面积、延迟、能量与反冲取舍 |
| PVT 与 Monte Carlo | 0/12 | 慢角延迟超限；统计 MOS 版本在两种极性均有错误判决 |
| 可靠性与面积 | 5/10 | ΣWL 有尺寸依据；缺工艺端间应力核对 |
| 交付与追溯 | 5/5 | 能复建原生工程；能从实际网表及波形复核 |

**项目自身成熟度按本轮证据为 54.5/100，基线为 52.5/100。** 这个数表示项目对长期目标的覆盖。11 项按新手体验、自主设计、专业设计、完整性、绘图、TB/Maestro、优化、鲁棒性、审查修复、可复现、软件维护排序，权重依次为 10、12、10、10、12、8、8、12、8、5、5。等级 0 表示无可用证据，1 表示仅有方法，2 表示已有局部执行，3 表示至少一个工程有完整的直接证据，4 要求不同拓扑上各有独立端到端验收。本轮等级依次为 2、1、2、2、3、3、2、2、2、3、3；基线仅 TB/Maestro 为 2。各项按“权重 × 等级 / 4”相加。独立生成任意拓扑、盲测新手完成率和量产良率均未验证。

## 跨电路的后续验收

比较器已作为前仿诊断案例归档。已有实际工艺下的原理图、可编辑的 Maestro 测试台、同条件尺寸对照、独立失配样本和可回放的失败波形。慢角延迟与失配仍有超限，具体数值保留在案例里。[尺寸取舍与实测边界](../examples/dynamic-comparator/SIZING_STUDY.md)

维护者已用一个 agent 从独立的公开源码副本完成一次从需求到交付的演练。输入是一句 8 µA ADC 偏置需求。旧入口仍使用 100 fF 和 200 ns，报告固定打开候选。修正后，在实际测试台回读到 250 fF，40 ns 上限用于三组实测；两版均达标时，直接打开栅面积较小一版的核心、symbol 和父级。额外对照覆盖了实测超限与输入待确认。这次记录覆盖维护者演练，首次使用者的独立完成率仍待测。[案例、测值与复跑命令](../examples/sky130-current-mirror/README.md#用一句-adc-偏置需求选方案)

单端 ADC 采样驱动器已完成跨电路复跑。由 7 位、1 pF 和 100 ns 推导指标，验证电源自偏置、双向大信号、实际采样开关及跟踪/保持两个环路工作点。初版通过 14/18 项，候选通过 18/18 项；规格收紧为 8 位后两版均超限。交付包含可编辑的层次、原始波形、可在下载工件上独立运行的复算命令。[采样驱动器与真实波形](../examples/sky130-adc-driver/README.md)

1. **采样驱动已从定位超限走到独立复验。** 原图慢角只剩 0.175 mV 标称余量，首批失配数据通过 14/32。按实际模型隔离输入对和有源负载的扰动，改型后保留了首轮独立复验 31/32 的失败。第二次冻结后在相同的 64 个新样本上，原图、第一版和最终版分别通过 33、64 和 64 个。最终版的最坏采样误差为 3.256 mV，核心栅面积从 172.60 增至 549.40 µm²。项目现可从真实测试台的失败追溯到器件，给出可编辑改型、面积代价与独立验证。这里的抽样限于给定慢角与局部 MOS 失配，新手独立完成情况另行记录。[原图的失配分布](../examples/sky130-adc-driver/README.md#slow-corner-mismatch) · [改型与未参与选型的新样本](../examples/sky130-adc-driver/MATCHING.md)
2. **已在两种公开工艺验证查表定尺寸。** 同一条 8 µA ADC 偏置在 SKY130 和 GF180 分别重扫 12,600 和 23,040 个 MOS 工作点，核对了表行、原生网表、仿真器回读的 W/L 和两管栅面积。GF180 照搬尺寸时最慢建立为 41.31 ns，按本工艺重选后为 37.91 ns，符合 40 ns 要求。验证范围为该电流镜与三组前仿工况。[两种工艺、照搬对照与原始数据复算](../examples/cross-pdk-current-mirror/README.md)
3. **让首次使用者独立验收。** 已备好一条使用 275 fF 新负载的需求和空白试用记录。首次使用者从公开仓库、可用工具和这句话开始，记录哪些参数需要本人确定、怎样打开选中图并复算，以及何处需要帮助。首次使用者的实际完成率待实测。[领取试用题](FIRST_USE_TRIAL.md)

在第二种 Cadence 有源拓扑上也完成了可编辑交付。SMIC18 偏置电流镜从本工艺的 6,516 个 MOS 工作点选尺寸。两种初始管长在 300 fF 负载下均超过 32 ns，重新选宽度后慢角建立为 31.21 ns，快角最大误差为 6.370%。核心、功能 symbol 和父级已在 Virtuoso 查看，六个 Maestro 测试的实际波形与直接 Spectre 独立对照。另以 1 ns 为上限，从原始结果确认全部七个合法尺寸超限。这一记录覆盖有理想外部参考的电流镜和三个确定性工况。[原生工程、尺寸与波形](../examples/smic18-bias-mirror/README.md)

采样驱动的 549.40 µm² 结果来自 ngspice 39。GitHub 的 ngspice 44.2 在同一较小候选、同一种子的开发误差上得到 3.512840 mV，刚好满足 3.515625 mV 的选型余量。该环境选中 477.40 µm²，最终 64/64 达标，最坏误差 3.599476 mV。新报告直接显示仿真器版本和余量阈值，两个版本的工件都可独立重算。[两个实测环境的同条件对照](../examples/sky130-adc-driver/MATCHING.md#为什么-github-选了更小的一版)

首次使用入口现可直接接收使用者的电流、负载、误差与时限。10 µA、200 fF 的规格在两种开源工艺都选出了达标的较小尺寸。把 8 µA、320 fF、8%、42 ns 送进 GitHub 的手动工作流后，两种工艺的 17 个合法尺寸全部超限，仍交付可打开的失败图和对应波形。两组云端工件均已在 Windows 从原始数据复算。首次使用者独立完成率继续以参加者的实际记录统计。[达标运行及图纸](https://github.com/w1213ph/virtuoso-circuit-skills/actions/runs/45773142617) · [自定义规格的超限运行](https://github.com/w1213ph/virtuoso-circuit-skills/actions/runs/45773303472)
