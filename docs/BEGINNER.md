# 第一次让 agent 搭建电路工程

可以从「我想做一个低功耗传感器放大器，输出接 ADC」开始。Agent 先从现有工程读取工艺、供电和可用模型，再确认会影响设计的输入、负载和使用条件。接下来由 agent 解释结构、选择器件、搭建并验证电路。

## 先准备什么

想看 agent 怎样把一个原本超限的电路改到达标，可以下载 8 位 ADC 采样驱动器。解压后打开 `index.html`，先看选中电路的采样波形，再展开尺寸表，比较只改电流镜、只改开关和两者都改时的结果。把自己的精度、负载和采样时间告诉 agent，即可用包内的 `--optimize` 入口重新设计。[下载优化工程](https://github.com/w1213ph/virtuoso-circuit-skills/releases/download/adc-driver-precision-v1/adc-driver-8bit-optimized.zip) · [复跑命令](../examples/sky130-adc-driver/README.md#precision)

如果已有 SMIC18 和 Cadence，可以直接说「给我一个 1.8 V 两级全差分运放，每侧带 2 pF，增益超过 80 dB，尽量省电」。Agent 可以从器件扫描一直做到可编辑的测试台。这个例子还保留了增益够、补偿却不足的一版，便于你对着波形理解为什么要换电容。[原理图、三工况读数和打开方法](../examples/smic18-ota-sizing/OTA.md)

有论文时提供 PDF 和复现范围。准备独立的新电路时，说明用途和已知条件。以传感器放大器为例，ADC 的输入负载和采样窗口决定需要多快建立，供电与输入范围影响可用结构。Agent 会把已知条件、建议目标和仍需确认的问题列在任务记录里。遇到确实影响性能取舍的未知项，再一起确定。

例如，你可以说“给 7 位、量化范围 1 V 的 ADC 驱动 1 pF，输入在 0.85 V 和 1.05 V 之间切换，100 ns 内采好，断开后保持 20 ns”。让 agent 把半个 LSB 换算成毫伏，画出放大器、偏置和实际采样开关，再用电容上的波形告诉你哪一版能用。可以直接下载这次工程，解压打开 `index.html` 看图，用 `python sample.py` 核对初版的四项超限和改型后的结果。[下载 7 位实测工程](https://github.com/w1213ph/virtuoso-circuit-skills/releases/download/adc-driver-7bit-v1/adc-driver-7bit.zip) · [用自己的规格重新设计](../examples/sky130-adc-driver/README.md)

真正生成 Virtuoso 电路需要可用的 Cadence、合法可访问的 PDK、仿真模型和连接工具。连接入口见 [SETUP.md](SETUP.md)。只有聊天环境时，可以先完成论文分析和设计计划；agent 应说明还缺哪些能力。

如果原理图在工艺角刚好达标，可以继续问“器件失配时还能采准吗？如果不行，告诉我该改哪只管，多大的面积才够，再用一批新样本证明”。本仓库的 7 位驱动器在慢角加入局部失配后，原图的 32 个样本只有 14 个同时达标。你可以打开最差波形，也可以让 agent 完成尺寸改型和独立复验。[原图的失败波形](../examples/sky130-adc-driver/README.md#slow-corner-mismatch) · [改型与复验入口](../examples/sky130-adc-driver/MATCHING.md)

想先看一次完整交付，可以把这句话发给 agent：“请运行 SKY130 电流镜案例。给我可以打开的原理图、测试台和第一次运行的报告，解释为什么加长沟道会改变输出误差，以及面积和速度的代价。”在有 Python、Xschem 和 ngspice 的 Linux 上可以复跑这个开源案例。[环境、命令与读图示例](../examples/sky130-current-mirror/README.md)

如果只知道“给 ADC 提供偏置电流”，先让 agent 查清参考电流由谁产生、输出向哪边供电流、负载接在哪个节点。已有外部参考时可以设计复制支路；需要芯片自己产生参考时，还要设计和验证参考源与启动。你可以直接说用途和已知数值，由 agent 保存原话、整理可测指标。负载暂时未知也可以先试算，报告会写清哪些结果还要等负载确认。下面这个实测案例展示了 250 fF 怎样进入测试台，以及报告怎样选中较小的方案。[从一句偏置需求到原理图与报告](../examples/sky130-current-mirror/README.md#用一句-adc-偏置需求选方案)

如果换了工艺，可以直接说：“把同一条 8 µA ADC 偏置从 SKY130 换到 GF180，重新测电流密度，告诉我照搬尺寸会在哪个指标上出问题。”公开案例中，照搬尺寸的直流精度合格，慢角建立却要 41.31 ns。报告给出了重新定尺寸后的图和两条实测波形。[跨工艺查表、原理图和慢角对照](../examples/cross-pdk-current-mirror/README.md)

第一次使用并希望检验自己能否独立交付，可以直接领取[单句需求与试用记录](FIRST_USE_TRIAL.md)。题目给出实际负载和验收指标，完成后记录自己打开的图、复算的结果和需要帮助的步骤。

如果你有 SMIC18 和 Cadence，可以让 agent “给 ADC 复制 8 µA 外部参考，参考节点接 300 fF，输出在 0.40–1.20 V 时误差最多 8%，开启后 32 ns 内稳定，把满足要求且栅面积最小的方案在 Virtuoso 里打开”。报告指出哪一组工况限制了尺寸。你也可以在 Maestro 中打开同一工况，直接查看输出电流怎样进入稳态范围。[实测波形、原理图与打开方法](../examples/smic18-bias-mirror/README.md)

## 复制这一段开始

```text
请使用 https://github.com/w1213ph/virtuoso-circuit-skills 帮我设计电路。
我是集成电路新手，请先读取仓库 AGENTS.md 和 skills/paper-to-virtuoso/SKILL.md，
按 references/paper-reproduction.md 的流程执行。

我的用途：[用一句话描述，按论文搭建时附上论文和图号]
目标工艺/电源：[填写，或从当前工程读取]
工程与连接：[填写，或读取已有配置]
我最关心的效果：[写你知道的，例如稳定驱动 ADC；请 agent 提出可测的指标]

请先读取工程，把已知条件、建议指标、测量条件和未决问题写清楚，
说明哪些设计选择需要我决定。给出初始尺寸、供电和功耗预算的依据。
请检查需要补充的偏置、共模反馈、参考、启动、关断、修调、
时钟和输出负载，解释哪些需要补充、为什么需要。
在独立任务库搭建实际 PDK 电路、功能 symbol、测试台与仿真环境。
先验证关键模块，再接整机。用前仿计划记录各指标，失败时保留证据。
电路应分层清楚、对称整齐、关键通路和反馈能沿实体线读懂。
工程注释说明作用、条件、设计目标与真实结果；图纸只描述当前功能，
不使用“去掉电容版”“改进版”等迭代过程名称。
给出器件有效尺寸、阵列总量和有依据的占地估算。
最后交付能打开的工程、真实截图、结果、限制、依赖及回退方法。
```

已有图只需要整理时，改用 [AI_START.md](AI_START.md) 的整理提示；那种任务不应自动改偏置、参数或启动仿真。

没有论文、要搭功能工程时，使用[工程搭建提示](AI_START.md#从功能需求搭建或继续工程)；已有电路需要性能提升时，使用[优化提示](AI_START.md#优化已有电路的性能)。常见模型/CDF、共模、时序、测量与交付问题已归纳为[排错清单](../skills/paper-to-virtuoso/references/lessons.md)，让 agent 按任务先检查。

## agent 应当让你看见什么

| 阶段 | 给新手看的结果 | 你可以检查什么 |
|---|---|---|
| 理解用途 | 功能链路、已知条件、建议目标和未决问题 | 实际要测的指标是否符合用途 |
| 选择实现 | 结构选择、器件、接口、偏置与初始尺寸的依据 | 电压、电流、负载和面积估算是否合理 |
| 验证模块 | 工作点、启动、极性、稳定性或时序结果 | 失败是否保留；条件是否明确 |
| 验证整机 | 用同一套条件比较目标、基线和候选测值 | 看到每个指标的结果、证据和未完成工况 |
| 完成交付 | 库/cell/view 入口、原理图、symbol、测试台 | 能否打开、看懂、复测和继续修改 |

例如，“增益正常”还不够。应写出频率、输入/输出及负载、增益定义与实际数值。差分增益正常也不能替代共模稳定性检查。

做可调增益放大器时，可以直接问 agent：“跑通 SKY130 可编程增益案例，告诉我最低码还有哪条支路工作，给我看四档在后级输入端的实测增益。若电源电流最多 20 µA，还有哪个版本可用？”默认报告同时给出切换两个端点的建立时间、失败工况和面积。把自己的电路交给 agent 时，再把接收节点、偏置来源、实际负载和控制位序换成你的条件。[四档增益、原理图与复跑命令](../examples/sky130-programmable-gain/README.md)

有 SMIC18 和 Cadence 时，可以在比较器案例中打开可编辑的 Maestro 测试台，查看一次真实判错和一次能量超限的波形。[测试台、波形与复跑命令](../examples/dynamic-comparator/SIZING_STUDY.md)

先看 [六管 OTA 实例](../examples/engineering-ota/README.md) 理解交付的样子。它的外部理想参考是已声明的测试条件；完整参考发生器、PVT 和版图并未由这个例子验证。新电路仍需自己的设计和验收。

流程帮助新手把任务交清楚，也约束 agent 交付证据。它不保证任意论文、工艺和指标一次成功；达不到的结果应如实保留，不能靠换测量定义变成“复现成功”。
