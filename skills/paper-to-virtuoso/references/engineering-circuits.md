# 从论文功能图补齐工程电路

按实际机制选用本页内容，不机械添加所有辅助电路。参考工程给的是可学习的组织方式；新工艺中的参数、行为和可靠性必须另行验证。

| 主题 | 为什么这样搭 | agent 实现时要追清 | 对应验证 |
|---|---|---|---|
| 分层与接口 | 把信号处理、参考、控制和测试分开，局部问题可定位 | 每级实际端口、方向/位序、共模、阻抗、电源与体端；核心和 TB 分开 | 展开接口及直接父级；真实加载后的结果 |
| 偏置和参考 | 为不同核提供合适电流、栅压、级联余量和驱动 | 参考/比例分配/局部生成依赖；启动、关断、修调 | [bias-design.md](bias-design.md) 的条件与模式检查 |
| 放大器主链 | 输入级、负载、级联、输出级分别承担 gm、增益和驱动 | 每级极性、工作区、输出共模和负载；不能只追差模通路 | 工作点、差模增益/带宽、真实负载与大信号恢复 |
| CMFB 与参考驱动 | 差模正确时输出共模仍可能漂移；动态负载会拉动参考 | 检测位置、反馈极性、注入点、与主环/其他环的耦合 | 共模工作点、各环及闭环交叉、实际扰动恢复 |
| 补偿与去耦 | 控制极点/零点或隔离负载变化 | 元件跨接节点、返回路径、直流与交流作用；阻抗/噪声/面积代价 | 电气改变后的稳定性、瞬态、信号传递；不能只看单个 PM 数字 |
| 混频与开关 | 时变接口决定转换、加载、反冲和相位 | gm/开关核/负载/LO 分工；I/Q、P/N、控制极性及导通区间 | 实际周期、输入匹配、转换、双向加载、谐波/边带敏感性 |
| 采样与参考 | 电荷共享和开关寄生可能影响精度与共模 | 采样/保持/复位相位、浮置节点、参考驱动与回路 | 实际 aperture、保持误差、kickback、状态/信号相关性 |
| 比较器和再生 | 前置放大、锁存、复位、输出保持需要时序配合 | 输入极性、再生交叉、复位有效态、时钟边沿、输出是否保留旧码 | 阈值扫描、历史依赖、真实参考/时钟下延迟和有效判决 |
| 数字控制/修调 | 使能、复位、模式码和模拟状态共同决定工作 | 真值表、位序、广播与逐成员映射；握手/VALID 对应哪个样本 | 边沿附近状态、跨周期资格、码字延迟、默认态与切换 |
| 可编程 R/C 阵列 | 单位单元便于匹配、比例与范围实现 | 段数/倍率、开关、基值、单位值、dummy；无源端口常需双向 | 实际展开值、全码范围/单调性、开关误差、合法 CDF 与原生网表 |
| 体端/井/保护/dummy | 约束衬底、结与版图边界；有些对象不承担主信号 | PDK 推荐连接、电压域和作用；不从名字臆断 ESD 或可靠性等级 | 实际端子/模型、规则适用性；若未做版图/ESD 签核就明确标注 |
| 测试点和 noConn | 使观察、调试与有意未用端口可辨认 | 测试负载是否反过来改变电路；noConn 是否确实有意 | 原生连接检查；输出阻抗或线性度不能带着理想隔离器冒充实际负载 |

## 把“为什么”落实成可执行设计

为每个采用的结构写一条机制记录：**解决的问题→实际连接/参数依据→代价→对应测试→当前结论**。有推算则标公式、条件和近似；有数值则注明是目标还是实际结果。只写“改善稳定性”“提高线性度”不足以指导下一个 agent。

例如：“输出级需要驱动电容负载，因此新增输出级；新增节点可能产生低频极点，先核对共模与静态余量，再测闭环稳定及压摆恢复。”不能把“输出级更大”直接当作带宽或精度通过。

镜像/差分/IQ 的**电气对称、参数对称、几何对称**分别核对。先展开数组、nf/m 和端子，再比较对应关系。不同支路可能有意不等尺寸；按照功能理解，不为视觉对称改变电路。

## 经验转成检查，而不是抄固定答案

- CDF 可能在初始化后重置未传入字段；回传完整独立参数且保留类型，用新进程 SI 核对实际展开。仅看显示值和 Check 零错误不够。
- 测试源属性名/相位用途可能因分析而不同；先检查真实差模/共模激励和采样时刻，避免把错误刺激当电路失败。
- 测参考梯要带真实比较器负载，测闭环要覆盖共模恢复，测 RF 要保留实际源/输出阻抗；隔离小样的通过不能自动转给整机。
- RF 每音功率、SSB/DSB 和 ADC 真实数字码的定义必须固定；理想重建、模拟节点观察和原生数字输出分别记录。
- 对“换更小电容/更大器件/更多位数”等候选，先判断接口噪声、稳定性和线性度限制；不能用一个改善指标覆盖其他失败。

用 [paper-reproduction.md](paper-reproduction.md) 把这些检查放入当前任务的阶段；原理图表达见 [engineering-schematic.md](engineering-schematic.md)。这些通用规则没有附带参考 IP 的专有拓扑、尺寸或截图。
