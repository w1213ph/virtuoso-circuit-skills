# 偏置与参考：怎样搭建，为什么这样搭建

这是设计判断与验收方法，不是某个 PDK 的固定尺寸配方。先理解电流流向、栅压来源、余量与启动依赖，再选择结构。只改图时不据此添加或重设计电路。

## 1. 先回答接口问题

为每个负载记录：需要电流还是栅压、源出还是吸入、典型电流和范围、输出电压范围、供电/体端、使能极性、负载电容及动态扰动。名字叫 IBIAS 的端口也要查真实连接：它可能接二极管参考支路而表现为电压节点，不能仅按名字决定方向或理想源类型。

画出“主参考→比例分配→局部电流/栅压生成→实际负载”的依赖图。辅助放大器的偏置来自哪里？全零初始状态下谁先导通？参考要靠受它控制的电路先工作时，应检查循环依赖与启动路径。

## 2. 按需要选择结构

| 结构 | 为什么使用 | 代价与检查 |
|---|---|---|
| 外部理想 IREF/VREF | 先隔离核心机制和接口，便于小样验证 | 只是外部条件；不包含真实发生器的功耗、噪声、PSRR、启动 |
| 二极管参考＋比例镜像 | 把参考电流转成栅压，在多个支路复制/缩放 | 相同 VGS 不代表相同电流；检查 VDS、体效应、失配、温度和输出电压范围 |
| 级联镜像 | 减小设定管漏压随输出变化，提高输出电阻 | 多占电压余量；需独立生成合适 cascode 栅压，不能全部栅极接同一 VBIAS |
| 源退化/电阻辅助栅压 | 用可计算压降设定工作点或级联余量，降低部分器件依赖 | 电阻误差/温漂、压降及噪声需要预算，不等于天然恒流 |
| 自偏置/温度补偿参考 | 以器件、电阻和反馈形成可分配的参考，减少外部理想依赖 | 可能有零电流平衡点；启动、电源变化、失配及环路稳定必须验证 |
| 局部再生偏置 | 给不同模拟核分配电流，在本地生成其需要的 N/P/级联栅压 | 额外功耗和启动依赖；不能假定全芯片共用一个栅压最合适 |
| 比例分支＋修调开关 | 用已定义的单位支路补偿工艺/模式差异 | 要定义编码、默认码、单调性、关断优先级及切换扰动 |

长沟道电流设定管可减弱部分短沟道效应，较大的匹配面积可降低部分随机误差；会增加寄生、面积和启动时间。应从输出电阻、噪声、匹配与速度预算选择，不能把参考设计中的长宽比当通用值。

## 3. 一条级联输出支路如何读

PMOS 源出支路可按以下次序阅读：

```text
VDD → 电流设定管（G=VBP）→ 内部节点 → 级联管（G=VCP）→ 负载
```

VBP 主要设定电流密度，VCP 主要约束内部节点与设定管余量。NMOS 吸入支路为负载经级联管、设定管到 VSS 的对应结构。必须核对实际 PDK 的 D/S/B，不能只按符号上下位置判断。

用长沟道近似，简单 NMOS 镜像在相近 VDS 且饱和时，`IOUT/IREF ≈ (W/L)OUT/(W/L)REF`；源端/体端、VDS 或工作区不同会破坏这个近似。级联输出电阻常有约 `gm·ro²` 的量级，但需以实际连接和工作点求得，不把这个表达式当所有镜像的精确结果。

先对整个输出电压范围做 DC 扫描，量电流误差与最小供电/输出余量，再谈 PSRR 或匹配。阵列实例数、nf 和 m 分别展开：两只实例并联、单实例 m=2、总线两位分别输出是不同语义。

## 4. 温度补偿参考为什么同时需要器件和反馈

以标准双极型参考原理为例：两个匹配 BJT 的电流密度比为 N，在理想条件下有 `ΔVBE = VT·ln(N)`，`VT=kT/q`。把这个差压加在 R 上形成 PTAT 电流；VBE 还提供 CTAT 分量。按电路比例组合，可以在设计温度附近抵消一阶温度系数。

不要把看到两个 BJT 就认作完整温度补偿参考。应沿真实连接写 KCL：面积比与电流比一起决定电流密度比；若支路还并接电阻，总镜像电流可能是 `ΔVBE/R1 + VBE/R2`，而不是只有 `ΔVBE/R1`。反馈放大器用来约束比较节点；其失调、有限增益、输入共模和自身偏置都会改变结果。

参考电流经电阻/抽头变为电压，再由缓冲器驱动负载，是几种不同任务。电压缓冲的反馈要查实际 IN+/IN−，并在真实负载下检查环路、容性负载和恢复。串联 RC 补偿不应仅凭“看起来像 Miller”确定零点；确认跨接节点和级数后再分析。

这些式子是原理近似，不是某工艺的温漂、PSRR 或噪声验证。使用实际模型在约定电源、温度、工艺和负载下测量。

## 5. 启动、关断和修调是电路的一部分

**启动**：标出在零电流附近提供扰动的器件、作用节点和稳态退出/残余电流条件。用多种供电上升时间、冷/热初态、重新使能与低电压检查；不同初值辅助求解可用于诊断，但不能靠强制初值宣布自然启动可靠。

**关断**：PMOS 参考栅压常钳向 VDD，NMOS 栅压常钳向 VSS，以形成明确的关闭状态；仍需按实际连接判定。只切断参考电流可能让偏置节点浮空或保留电荷。列真值表，验证输出安全态、漏电、反灌和恢复，而不只看逻辑信号翻转。

**修调**：建立 `总使能×局部使能×修调码→各支路开关与输出` 表。PMOS 开关低电平导通，不能只看到 OR/INV 门就按名字判断作用。对由同一单位电流组成的阵列，才可使用 `I≈Ibase+Σbk·Ik` 的初始估算；实际开关压降、输出余量与码相关变化还须扫量。

## 6. 布线、匹配与排错

参考支路、二极管连接、级联输出和关断钳位用实体线清楚画出。重复镜像支路同排、同向、等间距；设定管和级联管各自对齐。远距离分配可用同名网标，但保留支路作用与负载归属。

标明真正需要匹配的器件组及比例，并在版图交接时考虑方向、邻近环境、梯度、dummy、井/体端和互连。schematic 对称不证明版图已经匹配。D/S 短接的器件或两端同网的电阻可能用于 dummy/版图一致性，应先读作用再决定是否保留，不能因不参与理想 DC 就自动删除。

最少记录实际负载下的参考/输出电流、各级栅压、VDS/VDSAT 或适用余量、功耗范围，以及启动/关断/恢复结果。初建只完成标称 DC 时就写“标称 DC 已验证”，其余条件继续列为待验证。
