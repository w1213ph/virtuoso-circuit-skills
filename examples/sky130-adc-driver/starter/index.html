复算与重新设计

在解压目录的终端运行 python sample.py。Python 3 会核对可编辑图、实际网表和器件扫描，重算采样误差与相位裕度。返回 0 表示有方案达标，1 表示两组实测均超限，2 表示运行或证据有误。

可以用一句话告诉 agent 新的 ADC 位数、量化范围、输入电平、采样电容和跟踪／保持时间，让它更新 my-driver.json。在装有 Xschem 和 ngspice 的 Linux 上执行以下命令，首次运行会下载锁定的公开模型，输出目录应为新目录。

python3 sample.py run --out my-design
python3 sample.py verify --out my-design
